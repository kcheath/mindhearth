# Backend Documentation Archive

This folder contains archived backend-related documentation that was previously in the project root.

## Archived Documents

- **API_DOCUMENTATION.md** - Comprehensive API documentation for the Tsukiyo backend
- **API_ENDPOINTS_DOCUMENTATION.md** - Detailed list of all API endpoints used by the Flutter app
- **API_ENDPOINT_FIXES.md** - Documentation of API endpoint fixes and corrections
- **API_FLOW_DIAGRAM.md** - Complete flow diagram of all 89 published API endpoints
- **BACKEND_INTEGRATION_GUIDE.md** - Guide for integrating with the backend
- **BACKEND_INTEGRATION_TEST_PLAN.md** - Test plan for backend integration

## Archive Date

January 27, 2025

## Reason for Archive

All backend-related documentation has been moved to this archive folder. Going forward, all API contract documents and integration documents should be placed in the `/fortessa_shared` folder for centralized management.

## Note

These documents are kept for historical reference. For current API contracts and integration documentation, please refer to the `/fortessa_shared` folder.
